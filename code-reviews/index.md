A code review is a conversation about whether a change solves the intended problem clearly and safely. Learn to review behavior and communicate feedback that someone can act on.

## What You Will Learn

- Review a change in the context of its requirements.
- Write specific, respectful feedback.
- Respond to comments and verify revisions.

## Learning Path

1. [Reviewing a Change](reviewing-a-change.html)
2. [Writing Useful Review Feedback](writing-useful-feedback.html)
3. [Responding to Reviews](responding-to-reviews.html)

Work through the lessons in order, then complete the final practice task. Each lesson includes an example and a way to check your understanding.
