AI can help you explore a codebase, implement a focused change, and investigate a bug. The useful skill is learning how to direct that help, check the result, and understand the code you ship.

## What You Will Learn

- Choose between chat, completions, and an agent.
- Write focused prompts and supply useful project context.
- Review generated code and verify behavior with evidence.
- Set up a workshop agent and understand its tool loop.
- Handle permissions, private data, context limits, and cost.

## Before You Start

Be comfortable with [Git](../learn-git/), the [terminal](../terminal-skills/), [reading code](../reading-code/), and basic [testing](../testing/). Most lessons are tool-independent. The optional agent workshop uses Go and a hosted API; the offline loop demonstration and final coding exercise do not require an API key.

## Two Ways to Practice

For everyday development, follow the prompting, review, and testing lessons, then complete the capstone. To understand agent internals, continue through the setup lesson and offline tool-loop demo before adding more capabilities.

The setup lesson links to [Geoffrey Huntley’s coding-agent workshop](https://github.com/ghuntley/how-to-build-a-coding-agent) and credits it as a companion resource. The explanations and exercises here are written for this field guide. Upstream code and provider interfaces can change; check the linked sources before running them.
