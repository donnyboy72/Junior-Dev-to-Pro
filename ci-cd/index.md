Continuous integration checks changes in a shared environment. Delivery and deployment carry a verified artifact toward users. Learn the stages, failure signals, and controls that make this process dependable.

## What You Will Learn

- Distinguish integration, delivery, and deployment.
- Design repeatable checks for each proposed change.
- Plan releases, verification, and recovery.

## Learning Path

1. [Understanding CI/CD](understanding-ci-cd.html)
2. [Designing a CI Pipeline](designing-a-ci-pipeline.html)
3. [Deployment and Recovery](deployment-and-recovery.html)

Work through the lessons in order, then complete the final practice task. Each lesson includes an example and a way to check your understanding.
