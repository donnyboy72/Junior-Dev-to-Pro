An API is a contract that lets one program use another program’s capabilities. This module follows a task application from an HTTP request to a reliable client.

## What You Will Learn

- Read HTTP requests and responses.
- Handle authentication, errors, and pagination.
- Build a client that fails predictably.

## Learning Path

1. [HTTP and JSON](http-and-json.html)
2. [Authentication and API Errors](authentication-and-errors.html)
3. [Building a Reliable API Client](reliable-api-clients.html)

Work through the lessons in order, then complete the final practice task. Each lesson includes an example and a way to check your understanding.
