A pull request proposes a branch’s changes for discussion, validation, and integration. Learn to make a patch easy to understand and carry it through review.

## What You Will Learn

- Prepare a focused branch and inspect its diff.
- Describe behavior and validation clearly.
- Merge using team conventions and verify the outcome.

## Learning Path

1. [Preparing a Pull Request](preparing-a-pull-request.html)
2. [Describing and Updating a Pull Request](describing-and-updating-a-pr.html)
3. [Merging and Following Up](merging-and-follow-up.html)

Work through the lessons in order, then complete the final practice task. Each lesson includes an example and a way to check your understanding.
