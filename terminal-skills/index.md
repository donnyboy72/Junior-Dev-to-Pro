The terminal lets you navigate files, inspect output, and run development tools. These lessons use a POSIX-style shell such as Bash or Zsh; Windows learners can use WSL or adapt commands to PowerShell.

## What You Will Learn

- Navigate and inspect files safely.
- Combine commands with pipes and redirection.
- Understand environment variables, processes, and exit codes.

## Learning Path

1. [Navigating Files and Directories](navigation-and-files.html)
2. [Pipes, Redirection, and Search](pipes-and-search.html)
3. [Processes and Environment Variables](processes-and-environment.html)

Work through the lessons in order, then complete the final practice task. Each lesson includes an example and a way to check your understanding.
