Databases store information beyond a single program run. Learn to model related data, query it, and change it without leaving records inconsistent.

## What You Will Learn

- Create tables with constraints.
- Read and update related records with SQL.
- Use transactions, indexes, and migrations deliberately.

## Learning Path

1. [Tables and Relationships](tables-and-relationships.html)
2. [Querying and Changing Data](querying-data.html)
3. [Transactions, Indexes, and Migrations](transactions-and-migrations.html)

Work through the lessons in order, then complete the final practice task. Each lesson includes an example and a way to check your understanding.
