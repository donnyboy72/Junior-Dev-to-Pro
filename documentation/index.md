Documentation helps someone perform a task or understand a decision without needing the original author. Learn to write setup instructions, explain tradeoffs, and keep examples usable.

## What You Will Learn

- Write a README that supports a first successful run.
- Choose between tutorials, references, and decision records.
- Verify instructions alongside code changes.

## Learning Path

1. [Writing a Useful README](writing-a-useful-readme.html)
2. [Explaining Decisions and Interfaces](explaining-decisions-and-interfaces.html)
3. [Maintaining and Checking Documentation](maintaining-and-checking-docs.html)

Work through the lessons in order, then complete the final practice task. Each lesson includes an example and a way to check your understanding.
