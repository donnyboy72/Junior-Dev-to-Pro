Security is part of ordinary feature work: deciding who can access data, handling untrusted input, and protecting credentials. Practice these decisions using a small task application.

## What You Will Learn

- Identify trust boundaries and enforce ownership.
- Handle input without confusing data with executable instructions.
- Protect secrets and respond to an accidental exposure.

## Learning Path

1. [Authentication and Authorization](authentication-and-authorization.html)
2. [Handling Untrusted Input](handling-untrusted-input.html)
3. [Secrets and Secure Development Habits](secrets-and-secure-habits.html)

Work through the lessons in order, then complete the final practice task. Each lesson includes an example and a way to check your understanding.
