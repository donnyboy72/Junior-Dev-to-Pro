A build tool turns source files into an artifact people can run or publish. Learn to recognize build stages, use the project’s commands, and diagnose failures without relying on hidden local state.

## What You Will Learn

- Distinguish source, build steps, and artifacts.
- Define clear repeatable development commands.
- Investigate failures from the first useful error.

## Learning Path

1. [From Source to Artifact](source-to-artifact.html)
2. [Scripts and Task Runners](scripts-and-task-runners.html)
3. [Debugging Build Failures](debugging-builds.html)

Work through the lessons in order, then complete the final practice task. Each lesson includes an example and a way to check your understanding.
